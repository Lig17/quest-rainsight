What this forecast says.
And what it cannot.

RainSight shows a model estimate with its timing, units, and origin. Use it as decision support, not as a local observation or official warning.

01

One deterministic run

IFS high-resolution forecast from ECMWF Open Data. A deterministic model run has no calibrated probability or uncertainty range.

02

Intervals are explicit

Each amount is the difference between cumulative precipitation fields. This view reports millimetres of water-equivalent precipitation per three-hour interval.

03

Grid point, not gauge

City values use the nearest 0.25° model grid point. Local terrain and rainfall can differ. Total precipitation includes frozen precipitation as water equivalent.
